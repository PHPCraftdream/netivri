## Decisions
- The daemon applies changed files by polling every 2 s (same signature seen twice) and restarting the core on the same port, instead of a notification from the CLI or a hot swap of nodes: it needs no CLI change, also covers hand edits, and the cost is one connection drop per real change.
- An unattended refresh may only store a list that still gives every account nodes on its route; otherwise the old list stays and the reason is in `status`.
- Switching checks the stored nodes (not their liveness), all-or-nothing, and repeating a value never fails; `account add` is deliberately not checked.
- Output default is Ktav with a JSON fallback when the library is missing; scripts and agents ask for JSON; the e2e tests set `NETIVRI_OUTPUT=json`.
- Snapshots are Ktav only when the read-back equals the data; GPL-3.0-only, public checkpoints and "nothing irreversible without the user's word" stand.
