## Decisions
- Directory name for isolated runs is `.netivri` (the user: no "config" in the name, logs live there too); `--local` creates it, an existing one in the current directory is used on its own (current directory only, no parent walk); `--home` with `--local` is a usage error; a new directory has the default port 7890, so a second angel needs `--port`.
- The setting names `pre_socks5`/`post_socks5` stay although they take http and https (renaming would break configs); documented everywhere.
- Hop attribution is best effort and says `unknown hop` when it cannot tell; a connection that breaks mid-stream is not attributed; the address is only matched, never printed.
- No SDK is shipped (the user: "не будем публиковать SDK"); the contract is the CLI with `--json`, the local proxy port and the control channel; GPL-3.0-only would bind importers anyway.
- Opt-in names of the silent sites in DEBUG were not built (needs a new setting and makes the log unsafe to share).
