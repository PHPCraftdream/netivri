## Decisions
- Failed dials count toward "down" only across 2+ sites, or 10 in a row on one site (a dead node used for one site must still fail over): a single dead destination must not take a node down.
- Data coming back through a node (poller sees download bytes) clears its failed probes and, for 60 s, keeps failed probes from counting; failed dials are not hidden by it.
- WARN for node down/flapping only for first-tier nodes; repeats of fallback nodes go to a new DEBUG level; `logs` defaults to INFO and above.
- Connection events only through a wrapper when `OnConnEvent` is set; the wrapper is deliberately not "replaceable" so copies stay counted, and exposes `Upstream`/`ReadCached`.
- Deploy low-risk (non data-path) builds without waiting for CI, data-path builds only after green PR checks; always with auto-rollback.
