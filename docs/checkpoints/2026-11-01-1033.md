## Decisions
- UDP through account routes is refused (fail closed): a sticky group without UDP support would let Mihomo fall through to `MATCH,DIRECT`; Shadowsocks `udp=true` is rejected; the server wrapper drops and counts any UDP.
- QUIC protocols (Hysteria2, TUIC, ShadowQUIC) need a core lifecycle for UDP sockets (restart-style replacement: close old, then start new, restore old on failure; transport-specific endpoint keys): task #168; their partial work waits in worktrees.
