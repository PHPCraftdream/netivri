## Decisions
- SQLite through the pure-Go `modernc.org/sqlite` (release builds use `CGO_ENABLED=0`); adding it raised golang.org/x/* (x/crypto 0.48, x/net 0.50, x/sys 0.42, ...); `modernc.org/mathutil` is an audited license ignore (docs/licenses.md).
- The route group is a custom sticky group, not `select`/`url-test`: key (login, registrable domain by the public suffix list; IP literal per IP), the first binding takes the best healthy node (score = delay * (1+4*failRate) / (1+min(MiB/s,20)/20), near-equal tolerance max(20 ms, 15 %) broken by an fnv hash), the binding is kept while the node is healthy and moves only when it is down (2 probe or 3 dial failures; any success clears it); UDP uses the same site key; no fallback outside the route (fail closed).
- Speed comes only from real traffic (bytes per 5 s window read from Mihomo's connection trackers) plus probe delay and dial time; no synthetic speed tests, no fake load.
- No new config keys in the first version (retention 7 days raw, binding idle TTL 24 h are constants); a switch is added with persisted bindings.
- Daemon shutdown order: core, then the statistics flush, then the control server, then the state file removal, so `stats` after `down` sees everything; an unopenable store is logged and the daemon runs without statistics.
