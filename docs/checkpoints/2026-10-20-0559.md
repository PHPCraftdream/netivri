- npm distribution is esbuild-style (main launcher package + six optional platform packages, `libc: glibc` on Linux, no install scripts, no downloads); the publish job runs only on tag pushes and only if the `NPM_TOKEN` secret exists. The release workflow's `publish` job now needs the `install-test` job.
- Installers verify SHA256 of the archive against `SHA256SUMS` unconditionally (no bypass flag), install real files (no symlinks) with the Ktav library next to the binary, accept the `sha256sum` binary marker `*`.
- CI concurrency: push runs get their own group (stuck runs on `main` had blocked the next push for over an hour); only pull requests cancel superseded runs.
- Core routing: `Options.Node` builds one proxy with a fixed internal name and a single `MATCH` rule; pseudo-types (`direct`, `dns`, `reject`, `rematch`) are rejected because a direct "node" would dial the target itself.
