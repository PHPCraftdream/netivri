## Decisions
- Keep GPL-3.0-only over MIT or Apache-2.0, and do not split the repository, because the single binary links GPL code; the only way out is not linking it, a different architecture that is not planned.
- Checkpoints are public and are pushed with the code (the earlier local-only handling was dropped); the four local ones were squashed into a single commit instead of rewriting public history.
- npm publishing picks its authentication per run: `NPM_PUBLISH=off` skips, `NPM_TOKEN` present means token, otherwise OIDC; the first release needs the token because Trusted Publishing can be set up only for packages that already exist, and moving to Trusted Publishing later means deleting the secret.
- Help is text for people unless `--json` is given (an exception to "JSON when not a TTY"), and running `netivri` with no arguments prints it with exit 0 instead of a usage error.
- Nothing irreversible without the user's word: no `v0.1.0` tag, no merging of the Dependabot PRs, no restart of the user's daemon after installing a build, no `CODE_OF_CONDUCT.md` without a contact.
