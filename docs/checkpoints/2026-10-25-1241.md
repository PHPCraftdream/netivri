## Decisions

- chose the "account rule can only narrow the global rule" cascade for allowed_clients, enforced before the password check and before an `init` claim (VerifyFrom seam), because a refused address must never claim an unclaimed account
- chose `status` short by default and `--full` for everything (warm.nodes, stats, affinity), changing the default contract on purpose (documented in CHANGELOG)
- chose to persist bindings by node label (not member index) in stats.db schema 4, restored at core start, written every 30 s and before close
- chose to accept rush reviews with only test-hygiene P2/P3 findings and let CI decide, to stop endless review rounds
